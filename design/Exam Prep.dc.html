Deadlock Detection & Recovery

Deadlock คือสถานะที่กลุ่มของ process รอ resource ที่ process อื่นในกลุ่มถือไว้ และไม่มีใครทำงานต่อได้ ระบบที่ไม่ป้องกัน deadlock ล่วงหน้าต้อง ตรวจจับ (detect) แล้ว กู้คืน (recover) เมื่อเกิดขึ้น

เงื่อนไขของ Coffman

1Mutual Exclusion — resource ใช้ได้ทีละ process
2Hold and Wait — ถือ resource ไว้ขณะรอตัวอื่น
3No Preemption — แย่ง resource คืนไม่ได้
4Circular Wait — รอกันเป็นวง
deadlock.c
void *thread1(void *arg) {
pthread_mutex_lock(&A);
pthread_mutex_lock(&B); // รอ B
/* critical section */
}
void *thread2(void *arg) {
pthread_mutex_lock(&B);
pthread_mutex_lock(&A); // รอ A
}

ถ้าทั้งสอง thread lock ตัวแรกได้พร้อมกัน จะรอกันไม่สิ้นสุด แก้ได้ด้วย lock ordering ให้ทุก thread lock A ก่อน B เสมอ เพื่อตัด Circular Wait
