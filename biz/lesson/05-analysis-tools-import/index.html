Encoding กับภาษาไทย

การเปิดไฟล์ CSV ที่มีเนื้อหาภาษาไทย ต้องเลือกวิธีเข้ารหัส (Encoding) ที่เหมาะสม ไฟล์จึงจะอ่านได้ ถ้าเลือกผิด ตัวอักษรไทยจะแสดงเป็นสัญลักษณ์ที่อ่านไม่ออก ทั้งที่ข้อมูลในไฟล์ไม่ได้เสีย

เสริมEncoding ที่พบบ่อย

ไฟล์ภาษาไทยในปัจจุบันส่วนใหญ่ใช้ UTF-8 ใน Excel นำเข้าได้ที่ Data → From Text/CSV แล้วเลือก File Origin เป็น 65001: Unicode (UTF-8) ไฟล์เก่าจากระบบ Windows อาจใช้ Windows-874 (TIS-620) ถ้าเลือก UTF-8 แล้วยังอ่านไม่ออกให้ลองค่านี้

ตัวอย่างไล่ทีละขั้น

ฝ่ายขายได้ไฟล์ sales.csv มา เปิดแล้วชื่อสาขากลายเป็นอักขระประหลาด

  1. ไฟล์เป็น CSV → ค่าถูกแบ่งด้วย comma ซึ่ง Excel แยกคอลัมน์ให้ถูกแล้ว
  2. อาการคือภาษาไทยอ่านไม่ออก → ปัญหาอยู่ที่ Encoding ไม่ใช่ตัวแบ่งค่า
  3. นำเข้าใหม่โดยเลือกวิธีเข้ารหัสให้ตรงกับไฟล์
  4. เมื่ออ่านได้แล้วจึงไปขั้นถัดไป: ทำความเข้าใจข้อมูล → Clean Data

จุดที่มักพลาด

  • คิดว่า SQL เหมาะกับทุกคนในองค์กร — ตามสไลด์เครื่องมือที่เหมาะกับทุกคนคือ Excel
  • คิดว่า Excel สร้าง Machine Learning Model ได้ตามสไลด์ — งานนั้นอยู่ในรายการของ Python
  • สลับ CSV กับ TSV — C = Comma, T = Tab
  • ภาษาไทยเพี้ยนแล้วคิดว่าไฟล์เสีย — ให้ตรวจ Encoding ก่อน
  • ข้ามขั้น Clean Data ไปสรุปผลเลย — ลำดับคือ Import → Understand → Clean → Pivot Table → Visualize

สรุปก่อนสอบ

  • Excel: ทุกคนในองค์กร · Import/Export, EDA, Clean, สรุป, Visualize
  • SQL (Structured Query Language): Query จาก RDBMS · Data Analyst, Data Scientist, Data Engineer
  • Python: สร้าง Data Science / ML Models · Data Scientist, Data Engineer
  • ขั้นตอน: Import → Understand → Clean → สรุปด้วย Pivot Table → นำเสนอเป็นกราฟ
  • CSV = Comma-Separated Values · TSV = Tab-Separated Values
  • CSV ภาษาไทยต้องเลือก Encoding ให้ถูกจึงอ่านได้
