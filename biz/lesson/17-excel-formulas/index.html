สูตรลัด Excel ที่ใช้บ่อยในงานจริง

หมายเหตุจากเอกสาร

บทเรียนนี้เป็น เนื้อหาเสริม: คอร์ส "สูตรลัด Excel ที่ใช้บ่อยที่สุดในงานจริง" อยู่ในรายการที่เรียน แต่ไม่มีเอกสารใน docs/APP-BUSINESS/ เนื้อหาเขียนจากความรู้ทั่วไปของ Excel สูตรและตัวอย่างที่วิทยากรใช้อาจต่างจากนี้ ถ้ามีสไลด์หรือไฟล์แบบฝึกหัดของคอร์ส ให้ยึดตามนั้น

นึกภาพก่อน

ตารางยอดขาย 1,000 แถว หัวหน้าถามสามคำถาม: รวมเท่าไร เฉพาะสาขากรุงเทพเท่าไร และสินค้ารหัส P007 ราคาเท่าไร คำตอบคือสามสูตร: SUM, SUMIF และ XLOOKUP งานใน Excel ส่วนใหญ่ใช้สูตรวนอยู่ไม่ถึงยี่สิบตัว

พื้นฐานของสูตร

  • สูตรขึ้นต้นด้วย = เสมอ
  • A1:A10 คือ ช่วง (range) ตั้งแต่ A1 ถึง A10
  • ข้อความในสูตรต้องอยู่ใน เครื่องหมายคำพูด เช่น "กรุงเทพ"

การอ้างอิงเซลล์และเครื่องหมาย $

แบบเขียนเมื่อ copy สูตรไปเซลล์อื่น
RelativeA1เลื่อนตามทั้งแถวและคอลัมน์
Absolute$A$1ล็อก ทั้งแถวและคอลัมน์
Mixed$A1 หรือ A$1ล็อกเฉพาะคอลัมน์ หรือเฉพาะแถว

กด F4 ขณะแก้สูตรเพื่อสลับรูปแบบ ตัวอย่างที่ต้องใช้ $: คำนวณ VAT ทุกแถวโดยอ้างอัตราภาษีในเซลล์เดียว → =B2*$F$1

ฟังก์ชันสรุปผล

ฟังก์ชันทำอะไร
SUM(range)ผลรวม
AVERAGE(range)ค่าเฉลี่ย
MAX(range) / MIN(range)ค่าสูงสุด / ต่ำสุด
COUNT(range)นับเซลล์ที่เป็น ตัวเลข
COUNTA(range)นับเซลล์ที่ ไม่ว่าง (ทุกชนิด)

IF: ตัดสินใจ

text
=IF(เงื่อนไข, ค่าเมื่อจริง, ค่าเมื่อเท็จ)
=IF(C2>=50, "ผ่าน", "ไม่ผ่าน")

ซ้อนกันหรือใช้ร่วมกับ AND / OR ได้ เช่น =IF(AND(C2>=50, D2="ส่งงาน"), "ผ่าน", "ไม่ผ่าน")

สรุปแบบมีเงื่อนไข

ฟังก์ชันรูปแบบ
SUMIF=SUMIF(ช่วงเงื่อนไข, เงื่อนไข, ช่วงที่จะรวม)
COUNTIF=COUNTIF(ช่วง, เงื่อนไข)
AVERAGEIF=AVERAGEIF(ช่วงเงื่อนไข, เงื่อนไข, ช่วงที่จะเฉลี่ย)
SUMIFS / COUNTIFSหลายเงื่อนไข — ใน SUMIFS ช่วงที่จะรวมอยู่ตัวแรก
text
=SUMIF(B2:B9, "กรุงเทพ", E2:E9)
=COUNTIF(D2:D9, "Cash")
=SUMIFS(E2:E9, B2:B9, "กรุงเทพ", C2:C9, "Member")

VLOOKUPXLOOKUP
รูปแบบ=VLOOKUP(ค่าที่หา, ตาราง, ลำดับคอลัมน์, FALSE)=XLOOKUP(ค่าที่หา, ช่วงที่หา, ช่วงที่คืนค่า, ค่าเมื่อไม่พบ)
ทิศทางหาในคอลัมน์ ซ้ายสุด ของตาราง แล้วคืนค่าจากคอลัมน์ทางขวาหาได้ทุกทิศ

=XLOOKUP("P007", A2:A100, C2:C100, "ไม่พบ")

จุดที่มักพลาด

  • ลืม $ เมื่อ copy สูตรที่อ้างเซลล์คงที่ — เซลล์อ้างอิงจะเลื่อนตาม
  • ใช้ COUNT นับข้อความ — COUNT นับเฉพาะตัวเลข ต้องใช้ COUNTA
  • ลืม FALSE ใน VLOOKUP — จะค้นแบบใกล้เคียงและอาจได้ค่าผิดโดยไม่มี error
  • ให้ VLOOKUP หาค่าที่อยู่ทางซ้ายของคอลัมน์ค้นหา — ทำไม่ได้ ใช้ XLOOKUP
  • สลับลำดับ argument ของ SUMIF กับ SUMIFS — SUMIF ช่วงที่รวมอยู่ ท้าย ส่วน SUMIFS อยู่ หน้า
  • ตัวเลขถูกเก็บเป็นข้อความ (ชิดซ้าย) ทำให้ SUM ได้ 0

สรุปก่อนสอบ

  • สูตรขึ้นต้นด้วย = · A1 relative · $A$1 absolute · F4 สลับ
  • SUM, AVERAGE, MAX, MIN · COUNT นับตัวเลข · COUNTA นับเซลล์ไม่ว่าง
  • IF(เงื่อนไข, จริง, เท็จ) · ใช้กับ AND / OR ได้
  • SUMIF(ช่วงเงื่อนไข, เงื่อนไข, ช่วงรวม) · COUNTIF(ช่วง, เงื่อนไข) · SUMIFS(ช่วงรวม, ช่วง1, เงื่อนไข1, …)
  • VLOOKUP หาคอลัมน์ซ้ายสุด ต้องใส่ FALSE · XLOOKUP หาได้ทุกทิศ กำหนดค่าเมื่อไม่พบได้
  • TRIM, LEFT, RIGHT, MID, LEN, & · IFERROR(สูตร, ค่าทดแทน)
  • Error: #N/A ไม่พบ · #DIV/0! หารศูนย์ · #VALUE! ชนิดผิด · #REF! อ้างเซลล์ที่ถูกลบ · #NAME? ชื่อผิด
  • คีย์ลัด: Ctrl+T Table · Ctrl+Shift+L Filter · Alt+= AutoSum · Ctrl+E Flash Fill
