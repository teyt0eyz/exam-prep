Clean Data: ทำความสะอาดข้อมูล

นึกภาพก่อน

จะหาอายุเฉลี่ยของลูกค้า 5 คน: 28, 34, 41, 34 และ 250 ได้ค่าเฉลี่ย 77.4 ปี ซึ่งเป็นไปไม่ได้ ต้นเหตุคือค่า 250 ที่พิมพ์ผิดเพียงค่าเดียว และ 34 ที่เป็นลูกค้าคนเดิมถูกบันทึกซ้ำ ถ้าไม่ทำความสะอาดก่อน ผลวิเคราะห์ทุกอย่างที่ตามมาจะผิดตาม

ทำไมต้องทำความสะอาดข้อมูล

  • เป็น ขั้นตอนสำคัญก่อนทำการวิเคราะห์ข้อมูล (Data Analysis)
  • เพื่อให้ข้อมูลอยู่ใน รูปแบบที่เหมาะสม ใช้วิเคราะห์ต่อได้
  • เพื่อให้ผลการวิเคราะห์มีประสิทธิภาพ ไม่เกิด Bias
  • เพื่อหา Insights ที่ใช้สนับสนุนการตัดสินใจทางธุรกิจได้

คำอธิบายทีละขั้น

ตรวจข้อมูลทีละแถวก่อนวิเคราะห์

การทำความสะอาดข้อมูลเป็นขั้นตอนสำคัญก่อนวิเคราะห์ จะตรวจตามลำดับ: แถวซ้ำ (Duplicates) → ค่าว่าง (Missing Values) → ค่าผิดปกติ (Errors) → รูปแบบไม่ตรงกัน (Formatting)

เทคนิคง่าย ๆ สองอย่าง

เทคนิคใช้กับทำไมได้ผล
MAX, MINข้อมูล ตัวเลข (Numerical)ค่าที่ผิดปกติมักเป็นค่าสูงสุดหรือต่ำสุดของคอลัมน์
Filterข้อมูล หมวดหมู่ (Categorical)รายการใน Filter แสดงค่าที่ไม่ซ้ำทั้งหมด ค่าที่สะกดผิดจึงโผล่ให้เห็น

MAX และ MIN

text
=MAX(F2:F1001)     วันสิ้นสุดของข้อมูล
=MIN(F2:F1001)     วันที่เริ่มต้นของข้อมูล

=MAX(G2:G1001)     ราคาต่อหน่วยแพงที่สุด
=MIN(G2:G1001)     ราคาต่อหน่วยถูกที่สุด

หมายเหตุจากเอกสาร

ในสไลด์หน้า "การใช้ Max / Min" ป้ายกำกับเขียนว่า วันที่เริ่มต้น อยู่เหนือสูตร =MAX(F2:F1001) และ วันสิ้นสุด อยู่เหนือ =MIN(F2:F1001) ซึ่งสลับกับการทำงานจริงของสูตร: MIN ให้วันที่น้อยที่สุด (วันแรก) และ MAX ให้วันที่มากที่สุด (วันล่าสุด) บทเรียนนี้อธิบายตามการทำงานจริงของสูตร ถ้าข้อสอบถามเรื่องนี้ ให้ดูว่าโจทย์ถาม "สูตรให้ผลอะไร" หรือ "สไลด์เขียนว่าอะไร"

  • ในวงเล็บคือ ช่วงที่ต้องการหาค่า เช่น F2:F1001 คือเซลล์ F2 ถึง F1001
  • ช่วงเริ่มที่ แถว 2 เพราะแถว 1 เป็นหัวคอลัมน์ ข้อมูล 1,000 แถวจึงจบที่แถว 1001
  • ใช้กับคอลัมน์วันที่ได้: MIN ให้ วันแรก และ MAX ให้ วันสุดท้าย ของข้อมูล จึงรู้ว่าข้อมูลครอบคลุมช่วงใด

Filter

ตัวอย่างในสไลด์:

  1. Filter ที่คอลัมน์ B (Branch) เลือก เชียงใหม่
  2. เลือกคอลัมน์ N (Rating) แล้วดูค่า Average ที่แถบสถานะด้านล่าง
  3. เปลี่ยน Filter เป็นสาขาอื่นเพื่อเปรียบเทียบค่าเฉลี่ย

Filter ซ่อน แถวที่ไม่ตรงเงื่อนไขไว้ชั่วคราว ไม่ได้ลบข้อมูล เมื่อล้าง Filter แถวทั้งหมดกลับมา

จุดที่มักพลาด

  • ใช้ MAX/MIN ตรวจข้อมูลหมวดหมู่ — MAX/MIN ใช้กับ ตัวเลข ส่วนหมวดหมู่ใช้ Filter
  • คิดว่า Filter ลบข้อมูล — แค่ซ่อนชั่วคราว
  • เขียนช่วงรวมหัวคอลัมน์ เช่น F1:F1001 — ข้อมูลเริ่มที่แถว 2
  • คิดว่า Clean Data ทำหลังวิเคราะห์ — ต้องทำ ก่อน เพื่อไม่ให้เกิด Bias
  • มองว่า male กับ Male เหมือนกัน — สำหรับ Excel เป็นคนละค่าเมื่อจัดกลุ่ม ต้องปรับให้ตรงกัน (Data Formatting)

สรุปก่อนสอบ

  • Clean Data ทำ ก่อน วิเคราะห์ → ข้อมูลอยู่ในรูปแบบเหมาะสม · ไม่เกิด Bias · หา Insights ได้
  • 5 เรื่อง: Identify Duplicates · Identify Errors · Handle Missing Values · Data Formatting · Filtering & Sorting
  • MAX / MIN ตรวจข้อมูล Numerical (รวมถึงหาวันเริ่มต้นและวันสิ้นสุด)
  • Filter ตรวจข้อมูล Categorical และใช้เลือกเฉพาะกลุ่มเพื่อดูค่า Average
  • =MAX(G2:G1001) — ในวงเล็บคือช่วงที่ต้องการหาค่า เริ่มแถว 2 เพราะแถว 1 เป็นหัวคอลัมน์
