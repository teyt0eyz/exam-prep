Pivot Table พื้นฐาน

นึกภาพก่อน

มีใบแจ้งหนี้ 1,000 ใบกองอยู่บนโต๊ะ หัวหน้าถามว่า "สาขาไหนทำรายได้มากที่สุด" วิธีทำด้วยมือคือแยกกองตามสาขา แล้วบวกรายได้ของแต่ละกอง Pivot Table ทำสองอย่างนี้ให้ทันที: จัดกลุ่ม แล้วคำนวณ โดยไม่แตะข้อมูลต้นทาง

Pivot Table คืออะไร

  • เป็นเครื่องมือที่มีประสิทธิภาพในการ คำนวณ สรุป และวิเคราะห์ข้อมูลในเชิงเปรียบเทียบ ทำให้เข้าใจ เทรนด์ ในเรื่องต่าง ๆ ได้
  • ตัวอย่าง: ยอดขายเปรียบเทียบแต่ละเดือน แต่ละสาขา, เปอร์เซ็นต์การขายของสินค้าแต่ละหมวดหมู่

สไลด์แปล Gross income ว่า "รายได้" และ Gross margin (%) ว่า "เปอร์เซ็นต์รายได้" ในทางบัญชี Gross income หมายถึง กำไรขั้นต้น (รายได้หักต้นทุนขาย) และ Gross margin คือ อัตรากำไรขั้นต้น ข้อสอบในเว็บนี้ใช้คำแปลตามสไลด์

ไฟล์ประกอบการเรียนชื่อ EP3_Supermarket.xlsx ใช้ทุกบทรวมถึง Full Workshop ข้อมูลมี 1,000 แถว (แถว 2–1001) ครอบคลุมเดือน ม.ค.–มี.ค. 2019 และในไฟล์ชื่อสาขาเขียนเป็นภาษาอังกฤษว่า Bangkok, Chiangmai, Phuket

ข้อมูลแบบนี้เรียกว่าเก็บแบบ Transaction: มีหัวคอลัมน์หนึ่งแถว และ 1 แถว = 1 รายการ เรียงจากบนลงล่าง เป็นรูปแบบที่ Pivot Table ต้องการ

สร้าง Pivot Table

เสริมขั้นตอนใน Excel (สไลด์สาธิตสด ไม่ได้เขียนขั้นตอนไว้)

  1. คลิกเซลล์ใดก็ได้ในข้อมูล
  2. แท็บ Insert → PivotTable
  3. ตรวจช่วงข้อมูล แล้วเลือกวางใน New Worksheet
  4. ลาก field จากรายการ (PivotTable Fields) ลงใน 4 พื้นที่ด้านล่าง

ใน Pivot Table ที่สไลด์แสดง จะเห็นคำว่า Row Labels, Column Labels, Sum of Gross income และ Grand Total ซึ่งมาจากพื้นที่ 4 ส่วนนี้:

จุดที่มักพลาด

  • ลาก field ตัวเลขไปที่ Rows — จะได้หนึ่งแถวต่อหนึ่งค่า ไม่ได้สรุปอะไร
  • ลาก field ข้อความไปที่ Values แล้วสงสัยว่าทำไมไม่ได้ผลรวม — ข้อความสรุปได้แค่ Count
  • คิดว่า Pivot Table แก้ข้อมูลต้นทาง — เป็นเพียงมุมมองสรุป ข้อมูลเดิมไม่เปลี่ยน
  • แก้ข้อมูลต้นทางแล้ว Pivot Table ไม่เปลี่ยน — ต้องกด Refresh
  • สับสนงานของสองเครื่องมือ — Pivot Table สรุป ส่วน Pivot Chart แสดงเป็นภาพ

สรุปก่อนสอบ

  • Pivot Table = เครื่องมือ คำนวณ สรุป วิเคราะห์เชิงเปรียบเทียบ → เห็นเทรนด์
  • Pivot Table ใช้สรุปข้อมูล · Pivot Chart ใช้แสดงผลด้วยภาพ
  • ข้อมูล Invoice: Invoice ID ไม่ซ้ำ · 3 สาขา · Customer Type 2 แบบ · Product 6 หมวด · Payment 3 แบบ
  • Total = Unit price × Quantity · Cogs = Cost of goods sold (ต้นทุนขาย)
  • 4 พื้นที่: Rows · Columns · Values · Filters (หมวดหมู่ → Rows/Columns/Filters, ตัวเลข → Values)
  • รายได้ต่อสาขา: Rows = Branch, Values = Sum of Gross income
  • Grouping ช่วยให้เห็นภาพรวมและความสัมพันธ์ที่ซ่อนอยู่
