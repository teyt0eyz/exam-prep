Data Visualization: เลือกกราฟให้ถูกกับข้อมูล

นึกภาพก่อน

ยอดขายของสามสาขาคือ 33%, 34% และ 33% ถ้าวาดเป็นวงกลมจะเห็นสามชิ้นที่ดูเท่ากัน บอกไม่ได้ว่าสาขาไหนมากที่สุด ข้อมูลเดียวกันถ้าวาดเป็นแท่ง จะเห็นทันทีว่าแท่งกลางสูงกว่า กราฟที่ผิดประเภททำให้ข้อมูลที่ถูกต้อง สื่อสารผิด

หลักการ

หากใช้กราฟหรือแผนภาพ ผิดประเภท อาจทำให้สื่อสารผิดพลาดหรือเข้าใจได้ยาก ปัญหาที่พบบ่อยเวลาทำ Data Visualization:

  • ใช้วิธีนำเสนอข้อมูลไม่เหมาะสม
  • ทำออกมาแล้วดูยาก เข้าใจยาก
  • Stakeholders อยากได้แบบหนึ่ง ทั้งที่แบบอื่นเข้าใจง่ายกว่า

กราฟ 5 แบบ

กราฟข้อมูลที่ใช้ใช้เพื่อตัวอย่างในสไลด์
Scatter Plotตัวเลขทั้ง 2 ตัวแปรดูการกระจายตัว / เกาะกลุ่ม และ ความสัมพันธ์ ของข้อมูลรายได้กับยอดการซื้อ, จำนวนทิปกับยอดรวมค่าอาหาร
Line ChartTime Series (แกน X เป็นเวลา)ดู เทรนด์ ที่เปลี่ยนแปลงไปราคาหุ้น, ยอดขายสินค้ารายวัน
Bar Chartหมวดหมู่ (Categorical) กับตัวเลขเปรียบเทียบค่าระหว่างหมวดหมู่ยอดขายแต่ละหมวดหมู่, จำนวนพนักงานแต่ละสาขา
Pie Chartหมวดหมู่กับตัวเลข (เหมือน Bar Chart)ดู สัดส่วน% ยอดขายระหว่าง Online กับ Store
Box Plotตัวเลข (แยกตามกลุ่มได้)ดูการกระจายด้วย 5 ค่า และ Outliersค่าทิปที่ได้รับในวันพฤหัสกับวันศุกร์

Line Chart

  • แสดงผลโดย เชื่อมข้อมูลที่อยู่ติดกันด้วยเส้น
  • เส้นที่เชื่อมมีความหมายเพราะจุดถัดไปคือ "เวลาถัดไป" จึงไม่ควรใช้กับหมวดหมู่ที่ไม่มีลำดับ

Pie Chart: ข้อควรระวัง

หากมี สัดส่วนที่ใกล้เคียงกัน จะคาดการณ์ด้วยสายตายาก (ไม่ควรใช้) ให้เปลี่ยนเป็น Bar Chart

Box Plot: 5 ค่า

text
        ●           ← Outliers (แสดงเป็นจุด)
        ┬           ← Maximum
        │
     ┌──┴──┐        ← Quartile 3
     │     │
     ├─────┤        ← Quartile 2 (Median)
     │     │
     └──┬──┘        ← Quartile 1
        │
        ┴           ← Minimum
  • 5 ค่าคือ Minimum, Quartile 1, Quartile 2 (Median), Quartile 3, Maximum
  • ถ้าข้อมูลมีค่า Outliers จะถูกแสดงเป็น จุด แยกออกมา

เลือกกราฟจากคำถาม

อยากรู้อะไรกราฟ
ยอดขายเปลี่ยนไปอย่างไรในแต่ละเดือนLine Chart
สาขาไหนขายได้มากที่สุดBar Chart
Online กับ Store คิดเป็นกี่เปอร์เซ็นต์ของยอดขายPie Chart
คนที่จ่ายค่าอาหารมากให้ทิปมากขึ้นหรือไม่Scatter Plot
ทิปวันศุกร์กระจายตัวต่างจากวันพฤหัสอย่างไร มีค่าผิดปกติหรือไม่Box Plot

Mini-workshop ในสไลด์สรุปไว้ว่า Line Plot / Bar Chart เพื่อให้เห็น Trends และ Pie Chart เพื่อให้เห็นสัดส่วน

ตัวอย่างไล่ทีละขั้น

โจทย์: นำเสนอ Gross income ของ 3 สาขา แยกรายเดือน (ม.ค.–มี.ค.)

  1. แกนหนึ่งเป็น เวลา (เดือน) → เข้าเงื่อนไข Time Series
  2. ต้องการเห็นว่าแต่ละสาขา เพิ่มหรือลด → ต้องการดูเทรนด์
  3. เลือก Line Chart โดยให้แต่ละสาขาเป็นหนึ่งเส้น
  4. ถ้าเปลี่ยนโจทย์เป็น "สัดส่วนรายได้รวมของแต่ละสาขา" จึงใช้ Pie Chart แต่ถ้าสัดส่วนใกล้กันให้ใช้ Bar Chart แทน

จุดที่มักพลาด

  • ใช้ Scatter Plot กับข้อมูลหมวดหมู่ — ต้องเป็น ตัวเลขทั้งสองแกน
  • ใช้ Pie Chart เมื่อสัดส่วนใกล้เคียงกัน หรือใช้ดูเทรนด์ตามเวลา
  • คิดว่า Box Plot แสดง Mean — เส้นกลางกล่องคือ Median (Quartile 2)
  • คิดว่า Outliers คือปลายเส้นของ Box Plot — Outliers แสดงเป็น จุด นอกเส้น
  • ใช้ Line Chart กับหมวดหมู่ที่ไม่มีลำดับเวลา

สรุปก่อนสอบ

  • ใช้กราฟผิดประเภท → สื่อสารผิดหรือเข้าใจยาก
  • Scatter Plot: ตัวเลข 2 ตัวแปร → การกระจายตัวและความสัมพันธ์
  • Line Chart: Time Series (แกน X เป็นเวลา) → เทรนด์
  • Bar Chart: หมวดหมู่กับตัวเลข → เปรียบเทียบ
  • Pie Chart: หมวดหมู่กับตัวเลข → สัดส่วน · ไม่ควรใช้เมื่อสัดส่วนใกล้เคียงกัน
  • Box Plot: Minimum, Q1, Q2 (Median), Q3, Maximum · Outliers เป็นจุด
