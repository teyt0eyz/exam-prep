ChatGPT ใน Google Sheet: ติดตั้ง เรียกใช้ และเขียน Prompt

นึกภาพก่อน

ปกติถ้าจะให้ ChatGPT ช่วยดูข้อมูลใน Google Sheet ต้อง copy ตารางไปวางในหน้าแชต แล้ว copy คำตอบกลับมาวาง คอร์สนี้ติดตั้ง ChatGPT เป็น Add-on ไว้ในแถบข้างของ Google Sheet เลย เลือกช่วงเซลล์ พิมพ์คำสั่ง แล้วแทรกคำตอบลงเซลล์ได้ทันที

ภาพรวม

ChatGPT ทำงานคู่กับ Google Sheet ได้ โดยเฉพาะการ ดึงข้อมูลจาก Google Sheet ไปคำนวณหรือประมวลผลต่อ

ตัวอย่างงานที่ทำได้:

  • สรุปผลรวม (Aggregate Data) ของข้อมูลซื้อขาย
  • ดึงข้อมูลอัตราแลกเปลี่ยน จากเว็บไซต์เข้า Google Sheet
  • สร้าง Sale Pipeline อัตโนมัติ
จุดเด่นจุดด้อย
ดึงข้อมูลใน Google Sheet เข้าไปประมวลผลหรือคำนวณใน ChatGPT บนออนไลน์ได้Add-on ChatGPT มาจาก Third Party ทำให้ จำกัดการใช้งาน หรือมีค่าใช้จ่ายเพิ่มเติม
ทำงานตามวันเวลาที่กำหนดแบบอัตโนมัติ ได้ฟังก์ชันของ ChatGPT ใช้งานได้ไม่หมด เช่น คำแนะนำ หรือการแก้ไข Prompt
มี Add-on ChatGPT ใน Google Sheet

คอร์สนี้เหมาะกับพนักงานออฟฟิศที่เสีย Productivity ไปกับงาน Operation เช่น การแก้ไขข้อมูลใน Google Sheet และการหา Insight จากยอดขาย

การติดตั้งและเรียกใช้

ขั้นตอนเส้นทางเมนู
ติดตั้งExtension (ส่วนขยาย) → Add-on → Download → GPT for Docs (ชื่อเต็ม GPT for Docs™ Sheets™ Slides™)
เรียกใช้Extension (ส่วนขยาย) → GPT for Docs

ขั้นตอนตามภาพหน้าจอในสไลด์ (เมนูภาษาไทยของ Google Sheet):

  1. เมนู ส่วนขยาย → ส่วนเสริม → รับส่วนเสริม จะเปิดหน้า Google Workspace Marketplace
  2. ค้นคำว่า chatgpt แล้วเลือก GPT for Docs™ Sheets™ Slides™ → กดติดตั้ง
  3. เรียกใช้: ส่วนขยาย → GPT for Docs™ Sheets™ Slides™ → Start แถบ Chat จะเปิดทางขวา
  4. ในเมนูเดียวกันมี Enable GPT functions สำหรับเปิดใช้ฟังก์ชัน GPT ในเซลล์

ในแถบ Chat ของ Add-on: ปุ่ม New Chat เริ่มบทสนทนาใหม่ · ป้ายช่วงเซลล์ (เช่น A1:B16) บอกว่ากำลังส่งข้อมูลช่วงใดให้ ChatGPT · ใต้คำตอบมีปุ่ม Copy to Clipboard และ Insert to Sheet

การดูผลลัพธ์ทำได้สองทาง:

  • อ่านจาก Tab ของ GPT for Docs (แถบข้าง)
  • แทรกคำตอบเข้าเซลล์ ของ Google Sheet

วิธีเขียน Prompt สำหรับงาน Google Sheet

รูปแบบ: Action + Obj. + Detail (Detail เป็น Optional)

ส่วนความหมายตัวอย่าง
Actionคำกริยา ของงานใน Google Sheetget, sum, fill, calculate
Obj.กรรม ของ ActionInsight, ชื่อคอลัมน์, Data
Detailรายละเอียดเพิ่มเติมให้คำถามลงลึกRegression model, Outlier

ข้อควรระวังของ Detail: ถ้าลึกเกินไปจะทำให้คำตอบแคบตาม

ตัวอย่างการใช้งานจริง

ตัวอย่างในสไลด์: เลือกช่วง A1:B16 (Total Sale กับ Customer) → เลือก Analyze Range Data → พิมพ์ get insight from this data ChatGPT ตอบเป็นข้อ ๆ เช่น Total Sales Per Customer และอีกตัวอย่างหนึ่งพิมพ์ sum of Total Sale แล้วแทรกผลรวมลงเซลล์

ตัวอย่างไล่ทีละขั้น

โจทย์: คอลัมน์ยอดขายมีช่องว่างอยู่หลายช่อง ต้องการให้เป็น 0

  1. งานคือ "แก้ไขข้อมูลที่ว่าง" → ใช้คำสั่ง Complete Table
  2. ครอบเลือกช่วงเซลล์ ที่ต้องการก่อน
  3. เขียน prompt ตามรูปแบบ: Action = fill · Obj. = blank value · Detail = by 0 → fill blank value by 0
  4. ตรวจคำตอบในแถบข้าง แล้วแทรกเข้าเซลล์

จุดที่มักพลาด

  • ลืมเลือกช่วงเซลล์ก่อนถาม — เป็นข้อควรระวังข้อแรกในสรุปของคอร์ส
  • เลือกคำสั่งไม่ตรงกับงาน — หา Insight ใช้ Analyze Range Data · เติมช่องว่างใช้ Complete Table · สร้างตารางหรือสูตรใช้ Generate Table
  • ใส่ Detail ละเอียดเกินไป — คำตอบจะแคบตาม
  • สลับความหมายของสัญลักษณ์ — " " เน้น · - แยกตัวเลขกับข้อความ · [ ] ตัวแปร
  • คิดว่า Add-on เป็นของ Google หรือ OpenAI โดยตรง — เป็นของ Third Party จึงมีข้อจำกัดและอาจมีค่าใช้จ่าย

สรุปก่อนสอบ

  • ChatGPT ใน Google Sheet: ดึงข้อมูลไปคำนวณ/ประมวลผล เช่น Aggregate Data, ดึงอัตราแลกเปลี่ยน, Sale Pipeline อัตโนมัติ
  • จุดเด่น: ประมวลผลออนไลน์ · ทำงานตามเวลาอัตโนมัติ — จุดด้อย: Add-on Third Party (จำกัด/มีค่าใช้จ่าย) · ฟังก์ชันไม่ครบ
  • ติดตั้ง: Extension → Add-on → Download → GPT for Docs · ใช้งาน: Extension → GPT for Docs
  • 3 คำสั่ง: Generate Table (สร้างตาราง/สูตร) · Analyze Range Data (หา Insight) · Complete Table (แก้ค่าว่าง/ผิดปกติ)
  • Prompt: Action + Obj. + Detail (Detail optional; ลึกเกิน → คำตอบแคบ)
  • สัญลักษณ์: " " เน้นข้อความ · - แยกตัวเลขกับข้อความ · [ ] ตัวแปร
