Notion: Blocks, Markdown และ Shortcut

นึกภาพก่อน

เขียนเอกสารใน Word ต้องเลื่อนเมาส์ไปกดปุ่มหัวข้อ ปุ่ม bullet ปุ่มแทรกรูป ใน Notion มือไม่ต้องออกจากคีย์บอร์ด: พิมพ์ / แล้วตามด้วยชื่อสิ่งที่อยากได้ หรือพิมพ์สัญลักษณ์สั้น ๆ แล้วกด space block ก็เปลี่ยนชนิดให้ทันที

เสริมเทียบกับ Markdown มาตรฐาน

ใน Markdown ทั่วไป > คือ blockquote แต่ใน Notion > + space สร้าง Toggle list ส่วน Quote ใช้ " + space และ Notion รองรับ #, ##, ### + space สำหรับ Heading 1–3 ด้วย แม้สไลด์จะแสดงเฉพาะแบบ /h1

Block Handle (⋮⋮)

จุดหกจุดด้านซ้ายของ block เรียกว่า Block Handle หรือ Action Menu ใช้จัดการ block:

เมนูทำอะไร
Deleteลบ Block
Duplicateคัดลอก Block ซ้ำ
Turn intoเปลี่ยนรูปแบบ Block เป็น Block แบบอื่น
Turn into page inเปลี่ยน Block เป็น Page ในหน้าที่เลือก
Copy link to blockคัดลอกลิงก์ของ Block
Move toย้าย Block ไปไว้ใน Page ที่เลือก

Colorเปลี่ยนสีข้อความ หรือสีพื้นหลัง

รายการใน Turn into: Text, Heading 1–3, Page, To-do list, Bulleted list, Numbered list, Toggle list, Code, Quote, Callout, Block equation, Synced block, Toggle heading 1–3 และ 2 columns

Turn into คือเหตุผลที่บอกว่า "Block เปลี่ยนรูปแบบได้": ข้อความธรรมดาเปลี่ยนเป็น To-do, Heading หรือ Callout ได้โดยไม่ต้องพิมพ์ใหม่

คำสั่ง 3 ตระกูล

/ commands

  • พิมพ์ / ตามด้วย ประเภท block เพื่อเพิ่ม block — เช่น /bullet, /heading
  • พิมพ์ / ตามด้วย การดำเนินการ เพื่อใช้กับ block — เช่น /delete, /duplicate
  • พิมพ์ / ตามด้วย ชื่อสี เพื่อเปลี่ยนสี block — เช่น /red

[[ commands

  • Link to page: พิมพ์ [[ แล้วเลือกหน้า
  • สร้าง Sub-page: พิมพ์ [[ ตามด้วยชื่อ แล้วเลือก + เพิ่มหน้าย่อยใหม่
  • สร้างเพจใหม่ที่อื่น: พิมพ์ [[ ตามด้วยชื่อ แล้วเลือก ↗ เพิ่มเพจใหม่ใน…

+ commands

  • สร้าง Sub-page: พิมพ์ + ตามด้วยข้อความ
  • สร้างหน้าใหม่ที่อื่น: พิมพ์ + ตามด้วยข้อความ แล้วเลือก ↗ เพิ่มหน้าใหม่ใน…
  • Link to page: พิมพ์ + ตามด้วยชื่อของหน้าอื่น

Keyboard Shortcut

cmd/ctrl + Pเปิดการค้นหา หรือข้ามไปยังหน้าที่ดูล่าสุด
cmd/ctrl + Lคัดลอก URL ของหน้า
cmd/ctrl + [ย้อนกลับหน้า
cmd/ctrl + ]ไปข้างหน้า
cmd/ctrl + shift + Lสลับ โหมดมืด / โหมดสว่าง

ปรับแต่งข้อความ ไอคอน และหน้าปก

  • ลากคลุมข้อความเพื่อปรับรูปแบบอักษร สี และชนิด block — แถบเครื่องมือที่ขึ้นมามี Ask AI, Text (เปลี่ยนชนิด block), Link, Comment, B (หนา), i (เอียง), U (ขีดเส้นใต้), S (ขีดฆ่า), <> (โค้ด), √x (สมการ) และ A (สี)
  • เมนูสี A แบ่งเป็น COLOR (สีตัวอักษร: Default, Gray, Brown, Orange, Yellow, Green, Blue, Purple, Pink, Red) และ BACKGROUND (สีพื้นหลัง)
  • พิมพ์ **TEXT** เพื่อทำ ตัวหนา · พิมพ์ *TEXT* เพื่อทำ ตัวเอียง
  • ไอคอน: เลื่อนเมาส์ไปด้านบนของ Page จะขึ้นปุ่ม Add Icon · เปลี่ยนได้โดยคลิกที่ไอคอน · หน้าต่างเลือกไอคอนมีแท็บ Emojis / Icons / Custom (Custom คืออัปโหลดรูปเอง) และปุ่ม Remove
  • หน้าปก: เลื่อนเมาส์ไปด้านบนจะขึ้นปุ่ม Add Cover (คลิกแล้วขึ้นรูปปกอัตโนมัติ) → Change cover เพื่อเลือกหรืออัปโหลดรูปเอง · หน้าต่างเลือกปกมีแท็บ Gallery / Upload / Link / Unsplash · ปุ่ม Reposition ใช้เลื่อนตำแหน่งรูป
  • ปุ่มที่ขึ้นเหนือชื่อหน้ามีสามปุ่ม: Add icon, Add cover, Add description

จุดที่มักพลาด

  • ใช้ > + space แล้วคาดว่าจะได้ Quote — ได้ Toggle list · Quote ใช้ " + space
  • สลับ Page history กับ Trash — Page history กู้ เวอร์ชันเก่าของหน้าที่ยังอยู่ ส่วน Trash กู้ หน้าที่ถูกลบ
  • สลับ cmd/ctrl + L กับ cmd/ctrl + shift + L — ตัวแรกคัดลอก URL ตัวหลังสลับโหมดมืด/สว่าง
  • คิดว่า Lock page คือการตั้งรหัสผ่าน — เป็นการกันการแก้ไขโดยไม่ตั้งใจ
  • คิดว่าต้องลบ block แล้วพิมพ์ใหม่เมื่ออยากเปลี่ยนชนิด — ใช้ Turn into

  • Media blocks: Image, Web Bookmark, Video, Audio, Code, File
  • ทางลัด: [] To-do · - Bulleted · 1. Numbered · > Toggle · --- Divider · " Quote · /h1 Heading 1

  • cmd/ctrl + P ค้นหา · + L คัดลอก URL · + [ ย้อนกลับ · + ] ไปข้างหน้า · + shift + L โหมดมืด/สว่าง
  • **TEXT** ตัวหนา · *TEXT* ตัวเอียง
  • Page history → Restore version · Trash → Restore หน้าที่ลบ · Lock page กันการแก้ไข
