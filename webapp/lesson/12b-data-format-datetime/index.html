Data Format และ Data Format สำหรับ DateTime

หมายเหตุจากเอกสาร

Scope 2026A ข้อ 9 คือ "Data Format & Data Format for DateTime" ไม่มีสไลด์ในโฟลเดอร์ บทนี้เป็น เนื้อหาเสริม ครอบคลุมทั้งความหมาย "รูปแบบข้อมูล" (JSON, CSV, XML) และ "การจัดรูปแบบข้อมูลเพื่อแสดงผล" (ตัวเลข เงิน วันเวลา) สไลด์ที่เกี่ยวข้อง: String & Number (toFixed, Number(), toString()) และ Array (toLocaleString('th-TH'), toLocaleString('en-US'))

นึกภาพก่อน

วันที่ "2/11/2026" คนไทยอ่านว่า 2 พฤศจิกายน แต่คนอเมริกันอ่านว่า 11 กุมภาพันธ์ และคนไทยอาจเขียนปีเป็น 2569 คอมพิวเตอร์จึง เก็บ ข้อมูลในรูปแบบมาตรฐานที่ไม่กำกวม แล้วค่อย จัดรูปแบบ ให้ตรงกับภาษาของผู้อ่านตอนแสดงผล

รูปแบบข้อมูลที่ใช้แลกเปลี่ยน

รูปแบบตัวอย่างContent-Typeจุดเด่น

สไลด์ HTTP แสดง application/json, text/csv, application/xml, application/yaml ในรายการ Content-Type JSON แปลงกับ object ด้วย JSON.stringify / JSON.parse (บท Spread และ JSON)

Date object

js
const now = new Date();                       // เวลาปัจจุบัน
const d1 = new Date(2026, 10, 2);             // 2 พ.ย. 2026  ← เดือน 10 = พฤศจิกายน
const d2 = new Date('2026-11-02T09:30:00');   // จาก string แบบ ISO (เวลาท้องถิ่น)
const d3 = new Date(0);                       // 1 ม.ค. 1970 00:00:00 UTC (epoch)

Timestamp

  • Date.now() คืน จำนวนมิลลิวินาที ตั้งแต่ 1 ม.ค. 1970 00:00:00 UTC (Unix epoch)
  • ระบบอื่นบางระบบใช้ วินาที (Unix timestamp) ต้องคูณหรือหาร 1000 เวลาแปลง

คำนวณกับวันที่

js
const a = new Date('2026-11-02');
const b = new Date('2026-11-13');
const days = (b - a) / (1000 * 60 * 60 * 24);   // ลบกันได้ผลเป็นมิลลิวินาที → 11

const tomorrow = new Date(a);
tomorrow.setDate(a.getDate() + 1);               // setDate จัดการข้ามเดือนให้เอง
  • ลบ Date สองตัวได้ มิลลิวินาที: 1 วัน = 1000 × 60 × 60 × 24 = 86,400,000 ms
  • เทียบวันที่ด้วย < > ได้ แต่ === เทียบว่าเป็น object ตัวเดียวกัน ต้องเทียบ a.getTime() === b.getTime()
  • new Date(2026, 0, 32) → 1 ก.พ. 2026 (วันที่เกินจะเลื่อนไปเดือนถัดไปเอง)

ISO 8601 และ timezone

รูปแบบมาตรฐานสากล YYYY-MM-DDTHH:mm:ss.sssZ

js
new Date(Date.UTC(2026, 10, 2, 2, 30)).toISOString()
// "2026-11-02T02:30:00.000Z"
ส่วนความหมาย
2026-11-02ปี-เดือน-วัน (เดือนในข้อความนี้ เริ่มที่ 01 ไม่ใช่ 0)
Tตัวคั่นระหว่างวันที่กับเวลา
02:30:00.000ชั่วโมง:นาที:วินาที.มิลลิวินาที
ZUTC (Zulu time) — หรือเขียนเป็น offset เช่น +07:00
  • toISOString() แปลงเป็น UTC เสมอ — ประเทศไทยคือ UTC+7 เวลา 09:30 ในไทยจึงเป็น 02:30:00.000Z
  • เก็บและส่งวันเวลาระหว่าง frontend กับ backend ด้วย ISO 8601 ใน UTC แล้วค่อยแปลงเป็นเวลาท้องถิ่นตอนแสดง
  • JSON.stringify แปลง Date เป็น string ISO ให้เอง แต่ JSON.parse ไม่แปลงกลับ ได้ string ต้อง new Date(str) เอง
  • new Date('2026-11-02') (มีแต่วันที่) ถูกตีความเป็น UTC เที่ยงคืน ส่วน new Date('2026-11-02T00:00') (มีเวลา ไม่มี Z) เป็น เวลาท้องถิ่น

  • locale th-TH ใช้ ปฏิทินพุทธศักราช โดยอัตโนมัติ (+543)
  • Intl.DateTimeFormat('th-TH', options).format(date) ให้ผลแบบเดียวกัน และใช้ซ้ำได้
  • options ที่ใช้บ่อย: year, month ('numeric', '2-digit', 'short', 'long'), day, weekday, hour, minute, timeZone: 'Asia/Bangkok'
  • ห้องสมุดเช่น date-fns หรือ dayjs ช่วยจัดรูปแบบแบบกำหนดเอง เช่น format(date, 'dd/MM/yyyy')

จุดที่มักพลาด

  • ใช้ getMonth() แสดงผลตรง ๆ ได้เดือนน้อยไปหนึ่ง — ต้อง + 1
  • สับสน getDate() (วันที่) กับ getDay() (วันในสัปดาห์)
  • คิดว่า toISOString() เป็นเวลาไทย — เป็น UTC (ลงท้าย Z)
  • เทียบ Date ด้วย ===
  • คำนวณต่อจากผล toFixed ซึ่งเป็น string
  • ลืมว่า Date.now() เป็น มิลลิวินาที ไม่ใช่วินาที
  • คาดว่า JSON.parse คืน Date — คืน string
  • ใช้ en-US แล้วอ่าน 11/2 เป็น 11 กุมภาพันธ์

สรุปก่อนสอบ

  • รูปแบบข้อมูล: JSON (application/json, มาตรฐาน web API) · CSV (text/csv, ตาราง) · XML (application/xml, มี tag)
  • ตัวเลข: toFixed(2) ปัดเศษและคืน string · toLocaleString('th-TH') ใส่ , · { style: 'currency', currency: 'THB' } → ฿ · padStart(2, '0')
  • new Date(ปี, เดือน, วัน) เดือน 0–11 · getDate() 1–31 · getDay() 0–6 (0 = อาทิตย์) · getFullYear()
  • Date.now() / getTime() = มิลลิวินาที ตั้งแต่ 1 ม.ค. 1970 UTC · 1 วัน = 86,400,000 ms
  • ลบ Date ได้ ms · เทียบด้วย getTime() · วันที่เกินจะเลื่อนเดือนให้เอง
  • ISO 8601: YYYY-MM-DDTHH:mm:ss.sssZ · Z = UTC · toISOString() เป็น UTC เสมอ · ไทย = UTC+7
  • เก็บ / ส่งเป็น ISO UTC · แสดงด้วย toLocaleDateString / Intl.DateTimeFormat
  • th-TH ใช้ปี พ.ศ. (+543) · en-US เดือน/วัน/ปี · en-GB วัน/เดือน/ปี
  • JSON.stringify แปลง Date เป็น ISO string · JSON.parse ไม่แปลงกลับ
