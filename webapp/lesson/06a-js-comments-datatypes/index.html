Comments และ Data types ใน JavaScript

หมายเหตุจากเอกสาร

Scope 2026A ข้อ "Comments, Variables, Data types, Operator, & Functions" — Variables, Operator และ Functions มีสไลด์แล้วในบทอื่น บทนี้เติม Comments และ Data types ซึ่งไม่มีสไลด์โดยตรง (เนื้อหาเสริม) สไลด์ Variable กล่าวถึงข้อมูลแบบ number, string, boolean, object, array และ "primitive vs reference types"

นึกภาพก่อน

ข้อมูลในโปรแกรมเหมือนของในบ้าน: บางอย่างเป็นของชิ้นเดียวจบ (ตัวเลข ข้อความ) บางอย่างเป็นกล่องที่ใส่ของหลายชิ้น (object, array) JavaScript ต้องรู้ว่าของแต่ละชิ้นเป็น ชนิดใด จึงจะรู้ว่า + ควรบวกเลขหรือต่อข้อความ

Comments

ข้อความที่ JavaScript ข้ามไม่รัน ใช้อธิบายโค้ดหรือปิดโค้ดชั่วคราว

js
// comment บรรทัดเดียว: ตั้งแต่ // ถึงท้ายบรรทัด
let price = 100; // ต่อท้ายโค้ดได้

/*
  comment หลายบรรทัด
  ใช้อธิบายยาว ๆ หรือปิดโค้ดทั้งก้อน
*/

/**
 * JSDoc: comment แบบพิเศษที่อธิบาย function
 * @param {number} a
 * @param {number} b
 * @returns {number}
 */
function add(a, b) {
  return a + b;
}
แบบเขียนใช้เมื่อ
บรรทัดเดียว// ...อธิบายสั้น ๆ
หลายบรรทัด/* ... */อธิบายยาว หรือปิดโค้ดหลายบรรทัด
JSDoc/** ... */บอกชนิดของ parameter และค่าที่คืน editor นำไปแสดงคำแนะนำได้
  • comment ซ้อนแบบ /* /* */ */ ไม่ได้ — */ ตัวแรกปิดทันที
  • comment ใน HTML ใช้ <!-- --> และใน CSS ใช้ /* */ เท่านั้น (CSS ไม่มี //)
  • comment ที่ดีอธิบาย ทำไม ไม่ใช่ทวนว่าโค้ดทำอะไร

Truthy และ falsy

ค่าที่ถูกมองเป็น false ใน if มีเพียง 8 ค่า:

false · 0 · -0 · 0n · "" (string ว่าง) · null · undefined · NaN

ทุกอย่างที่เหลือเป็น truthy รวมถึง "0", "false", " ", [] และ {}

js
if ([]) console.log("array ว่างเป็น truthy");      // พิมพ์
if ("0") console.log('"0" เป็น truthy');            // พิมพ์
if (0) console.log("ไม่พิมพ์");

จุดที่มักพลาด

  • ตอบว่า typeof null คือ "null" — คือ "object"
  • ตอบว่า typeof [] คือ "array" — คือ "object" ต้องใช้ Array.isArray
  • คิดว่า [] และ {} เป็น falsy — เป็น truthy
  • คิดว่า "0" เป็น falsy — string ไม่ว่างเป็น truthy เสมอ
  • ตรวจ NaN ด้วย x === NaN — ใช้ Number.isNaN(x)
  • สับสน + กับ - เมื่อมี string — + ต่อข้อความ - แปลงเป็นเลข
  • ใช้ // ใน CSS — CSS มีแค่ /* */

สรุปก่อนสอบ

  • Comment: // บรรทัดเดียว · /* */ หลายบรรทัด (ซ้อนไม่ได้) · /** */ JSDoc · HTML <!-- --> · CSS /* */
  • 7 primitive: string, number, bigint, boolean, undefined, null, symbol + object
  • typeof null = "object" · typeof [] = "object" · typeof NaN = "number" · typeof fn = "function"
  • undefined = ยังไม่กำหนด · null = ไม่มีค่าโดยตั้งใจ · null == undefined true · === false
  • Primitive คัดลอกค่า · object คัดลอกตัวอ้างอิง · {} === {} false
  • + กับ string → ต่อข้อความ · - * / → แปลงเป็นเลข · แปลงไม่ได้ → NaN
  • Falsy 8 ค่า: false, 0, -0, 0n, "", null, undefined, NaN · ที่เหลือ truthy รวม "0", [],
  • NaN === NaN false → Number.isNaN · 1/0 = Infinity · 0.1 + 0.2 ≠ 0.3
