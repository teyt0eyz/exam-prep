CSS: วิธีใส่ style ให้ element, selector, box model และ flexbox

หมายเหตุจากเอกสาร

ส่วนต้นของบท (style attribute และ 4 วิธีใส่ style) มาจากเอกสาร HTML Styling และ Methods for Applying Style to Elements ตั้งแต่หัวข้อ "โครงของ rule" ลงไป (selector, box model, flexbox, responsive) เป็น เนื้อหาเสริม ที่ไม่มีในเอกสาร

นึกภาพก่อน

HTML คือโครงบ้าน: มีห้อง มีประตู มีหน้าต่าง CSS (Cascading Style Sheets) คือการทาสี จัดวางเฟอร์นิเจอร์ และกำหนดระยะห่าง บ้านหลังเดียวกันเปลี่ยน CSS แล้วหน้าตาเปลี่ยนได้ทั้งหลังโดยไม่แตะโครง

Style attribute (สไลด์ HTML Styling)

attribute style ใช้ใส่ inline CSS ให้ element ตัวเดียวโดยตรง แก้สี ฟอนต์ ขนาด และระยะห่างได้โดย ไม่ต้องมี stylesheet ภายนอก

html
<tagname style="property: value;">
ตัวอย่างในสไลด์property ที่ใช้
<p style="color: blue;">สีตัวอักษร
<div style="background-color: lightblue;">สีพื้นหลัง
<h1 style="font-size: 36px; font-family: Arial;">ขนาดและชนิดฟอนต์
<h1 style="text-align: center;">จัดข้อความ ซ้าย กลาง หรือขวา
<p style="padding: 10px; margin-bottom: 20px;">ระยะห่าง ด้านในและด้านนอก
<div style="display: none;">ซ่อน element

ใส่หลาย property ได้โดยคั่นด้วย ;:

html
<button style="color: white; background-color: red; border: none; padding: 10px 20px;">
  Click Me
</button>

<a href="#" style="color: white; background-color: green; padding: 8px 16px;
   text-decoration: none; border-radius: 4px;">
  Call to Action Button
</a>
propertyทำอะไร
padding: 10px 20pxสองค่า = บน-ล่าง 10px, ซ้าย-ขวา 20px
text-decoration: noneเอาเส้นใต้ของ link ออก
border-radius: 4pxมุมโค้ง
border: noneไม่มีเส้นขอบ

MDN: ไม่แนะนำให้ใช้ style attribute สร้างทั้งเว็บ ควรเก็บไว้ใช้กับการ ทดสอบเร็ว ๆ, prototype หรือการเปลี่ยนแบบ dynamic ที่คุมด้วย JavaScript โปรเจกต์ใหญ่ควรแยก stylesheet เพื่อนำกลับมาใช้ซ้ำและให้โครงสร้างสะอาด

4 วิธีใส่ style (เอกสาร Methods for Applying Style)

1. Inline styles

  • ใส่ CSS ให้ element เดียว ผ่าน attribute style ใน tag เปิด
  • <h1 style="color: blue; font-size: 24px;">This is a blue heading</h1>
  • เหมาะกับ: ทดสอบ, debug หรือ override style ครั้งเดียว
  • ข้อเสีย: ดูแลยาก และทำให้โครงสร้าง HTML รก

2. Internal stylesheets

  • เขียนใน element <style> ภายใน <head> ของเอกสารหน้านั้น ใช้ selector และ ruleset ตามปกติ
html
<head>
  <style>
    p {
      color: darkgreen;
      line-height: 1.5;
    }
  </style>
</head>
  • เหมาะกับ: เว็บหน้าเดียว หรือหน้าที่ต้องมี style เฉพาะ
  • ข้อเสีย: นำ style ไปใช้ร่วมกับไฟล์อื่นในเว็บไม่ได้

3. External stylesheets

  • เขียน CSS ในไฟล์ .css แยก (เช่น styles.css) แล้วเชื่อมด้วย <link> ใน <head> — เอกสารเรียกว่า มาตรฐานของงาน production
html
<head>
  <link rel="stylesheet" href="styles.css">
</head>
css
/* styles.css */
body {
  background-color: #f0f0f0;
}
  • เหมาะกับ: เว็บหลายหน้า ให้ดีไซน์สม่ำเสมอและโหลดเร็ว
  • ข้อเสีย: browser ต้องส่ง HTTP request เพิ่มหนึ่งครั้ง แต่ cache ช่วยได้

4. Dynamic JavaScript styling

เปลี่ยนหน้าตาขณะหน้าเว็บทำงาน เพื่อตอบสนอง event (เช่น click หรือ hover)

js
// Method A: Direct Style Property — แก้ inline style ของ element โดยตรง
document.getElementById("myButton").style.backgroundColor = "red";

// Method B: Class Manipulation (แนะนำ) — สลับ class ที่เขียนไว้ใน CSS ด้วย classList
document.getElementById("myButton").classList.add("active-state");

ในโค้ด JavaScript ชื่อ property ที่มีขีด เช่น background-color เขียนแบบ camelCase เป็น backgroundColor

ตารางเทียบ

InlineInternalExternal
ที่อยู่ (Location)บน tag HTML โดยตรงใน <style> ใน headไฟล์ .css แยก
ขอบเขต (Scope)element เดียวเอกสาร HTML หน้าเดียวทั้งเว็บ (ทุกหน้าที่ link)

หมายเหตุจากเอกสาร

ตารางในเอกสารให้ specificity ของ internal "กลาง" และ external "ต่ำ" ตามความเป็นจริงของ browser inline ชนะทั้งสองแบบจริง แต่ internal กับ external มีน้ำหนักเท่ากัน ถ้า selector เหมือนกัน ตัวที่ ประกาศทีหลัง ในหน้าเป็นฝ่ายชนะ (มักเป็น <style> เพราะวางหลัง <link>) ข้อสอบในเว็บนี้ตอบตามตารางของเอกสาร

โครงของ rule

css
selector {
  property: value;
}

h1 {
  color: navy;
  font-size: 24px;
}

Selector

Selectorเขียนเลือกอะไร
Elementpทุก tag <p>
Class.cardทุก element ที่มี class="card"
ID#demoelement ที่มี id="demo" (ควรมีตัวเดียวในหน้า)

selector ชุดเดียวกันนี้ใช้กับ document.querySelector() ในบท DOM

Specificity: ใครชนะเมื่อชนกัน

inline style > ID > class > element ถ้าน้ำหนักเท่ากัน ตัวที่เขียนทีหลังชนะ

css
p { color: black; }        /* element */
.note { color: blue; }     /* class ชนะ element */
#main { color: red; }      /* ID ชนะ class */

<p id="main" class="note"> จึงเป็นสีแดง

Box model

ทุก element เป็นกล่องสี่ชั้น จากในออกนอก:

text
┌──────────── margin ────────────┐   ระยะห่างจากกล่องอื่น (นอกเส้นขอบ)
│ ┌────────── border ──────────┐ │   เส้นขอบ
│ │ ┌──────── padding ───────┐ │ │   ระยะระหว่างเนื้อหากับเส้นขอบ (ในเส้นขอบ)
│ │ │        content         │ │ │   เนื้อหา: width × height
│ │ └────────────────────────┘ │ │
│ └────────────────────────────┘ │
└────────────────────────────────┘
box-sizingwidth หมายถึง
content-box (ค่าเริ่มต้น)เฉพาะ content → ความกว้างจริง = width + padding + border
border-boxcontent + padding + border → ความกว้างจริง = width

display

ค่าพฤติกรรมตัวอย่าง tag
blockขึ้นบรรทัดใหม่ กว้างเต็มแถว<div>, <p>, <h1>
inlineอยู่ในบรรทัดเดียวกับข้อความ กำหนด width/height ไม่ได้<span>, <a>, <b>
inline-blockอยู่ในบรรทัด แต่กำหนดขนาดได้
noneไม่แสดงและไม่กินพื้นที่
flexจัดลูกในแนวเดียวด้วย flexbox

Flexbox

ใส่ display: flex ที่ ตัวแม่ (container) แล้วลูกจะเรียงตามแกนหลัก

css
.row {
  display: flex;
  flex-direction: row;             /* แกนหลัก: row (แนวนอน) หรือ column (แนวตั้ง) */
  justify-content: space-between;  /* จัดตามแกนหลัก */
  align-items: center;             /* จัดตามแกนขวาง */
  gap: 12px;                       /* ระยะห่างระหว่างลูก */
}
Propertyทำอะไรค่าที่ใช้บ่อย
justify-contentจัดตาม แกนหลักflex-start, center, flex-end, space-between
align-itemsจัดตาม แกนขวางstretch, center, flex-start, flex-end
flex-directionทิศของแกนหลักrow, column
flex-wrapให้ขึ้นแถวใหม่เมื่อไม่พอnowrap, wrap

จัดกึ่งกลางทั้งสองแกน: display: flex; justify-content: center; align-items: center;

หน่วยและ responsive

หน่วยความหมาย
pxพิกเซล ค่าตายตัว
%ร้อยละของตัวแม่
em / remเทียบกับขนาดตัวอักษรของตัวเอง / ของ root
vw / vhร้อยละของความกว้าง / ความสูงหน้าจอ
css
.cards { display: flex; flex-direction: column; }

@media (min-width: 768px) {
  .cards { flex-direction: row; }   /* จอกว้าง 768px ขึ้นไป เรียงแนวนอน */
}

media query ใช้ rule ภายในเฉพาะเมื่อเงื่อนไขของหน้าจอเป็นจริง

ตัวอย่างไล่ทีละขั้น

css
.box { width: 200px; padding: 20px; border: 5px solid black; margin: 10px; }
คำถามคิดคำตอบ
ความกว้างที่มองเห็น (ถึงเส้นขอบ) แบบ content-box200 + 20 × 2 + 5 × 2250px
พื้นที่แนวนอนที่กล่องกินรวม margin250 + 10 × 2270px
ถ้าเพิ่ม box-sizing: border-box ความกว้างที่มองเห็นwidth รวม padding และ border แล้ว200px
ความกว้างของ content ในกรณี border-box200 − 40 − 10150px

จุดที่มักพลาด

  • สลับ padding กับ margin — padding อยู่ ใน เส้นขอบ (พื้นหลังของกล่องครอบคลุมถึง) ส่วน margin อยู่ นอก
  • ลืมว่า padding และ border บวกเพิ่มจาก width ใน content-box
  • ใส่ justify-content ที่ตัวลูก — property ของ flexbox ส่วนใหญ่ใส่ที่ ตัวแม่
  • สลับ justify-content กับ align-items เมื่อเปลี่ยนเป็น flex-direction: column — แกนหลักกลายเป็นแนวตั้ง
  • ใช้ # กับ class หรือ . กับ id — . คือ class และ # คือ id
  • คิดว่า display: none ยังกินพื้นที่ — ไม่กิน (ที่ยังกินพื้นที่คือ visibility: hidden)

สรุปก่อนสอบ

  • style attribute: <tagname style="property: value;"> ใส่ CSS ให้ element เดียว · MDN แนะนำให้ใช้แค่ทดสอบ prototype หรือ dynamic
  • 4 วิธี: inline (style) · internal (<style> ใน head) · external (<link rel="stylesheet"> ใน head, มาตรฐาน production) · JavaScript
  • Scope: inline = element เดียว · internal = หน้าเดียว · external = ทั้งเว็บ
  • Specificity: inline สูงสุด · internal กลาง · external ต่ำ · Maintainability: inline แย่ · external ดีเยี่ยม
  • External เสีย HTTP request เพิ่ม แต่ cache ช่วยได้ · Internal ใช้ร่วมข้ามไฟล์ไม่ได้
  • JavaScript: el.style.backgroundColor = "red" (แก้ตรง) หรือ el.classList.add("active-state") (แนะนำ)
  • padding: 10px 20px = บน-ล่าง 10, ซ้าย-ขวา 20 · display: none ซ่อน
  • Selector: p element · .card class · #demo id · ul li descendant · a:hover pseudo-class
  • Specificity: inline > id > class > element · เท่ากันตัวหลังชนะ
  • Box model จากในออกนอก: content → padding → border → margin
  • content-box: ความกว้างจริง = width + padding + border · border-box: ความกว้างจริง = width
  • block ขึ้นบรรทัดใหม่ · inline อยู่ในบรรทัด · none ไม่แสดงไม่กินที่
  • Flexbox: display: flex ที่ตัวแม่ · justify-content แกนหลัก · align-items แกนขวาง
  • @media (min-width: 768px) ใช้ rule เมื่อจอกว้างตามเงื่อนไข
