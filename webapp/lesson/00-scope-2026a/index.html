นอก Scope

บทเหล่านี้ยังอยู่ในเว็บเพื่อความเข้าใจภาพรวม แต่ ไม่มีข้อสอบจำลองแล้ว:

  • ฐานข้อมูล SQL · MongoDB · Authentication / JWT · Bruno

ลำดับอ่านที่แนะนำ (สอบจันทร์ 2 พ.ย.)

  1. หัวข้อที่ไม่มีสไลด์ อ่านก่อน เพราะเป็นส่วนที่ยังไม่เคยเห็น: Engine และ Runtime · Node.js และ npm · Semantic Versioning · Flex และ Grid · Data Format และ DateTime · Git · Environment Variable
  2. JavaScript ที่มีสไลด์ ทบทวนเร็ว ๆ ผ่านกล่อง "สรุปก่อนสอบ" ท้ายแต่ละบท
  3. ทำข้อสอบจำลองครบ 3 ชุด แล้วอ่านคำอธิบายของข้อที่ผิด หน้าผลสอบแสดงคะแนนแยกตามหัวข้อ ให้กลับไปอ่านบทของหัวข้อที่ได้น้อยที่สุด
