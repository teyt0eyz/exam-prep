HTML พื้นฐาน

นึกภาพก่อน

เขียนรายงานใน Word เรากดปุ่มเพื่อบอกว่า "ตรงนี้คือหัวข้อ" "ตรงนี้คือย่อหน้า" "ตรงนี้ตัวหนา" HTML ทำสิ่งเดียวกันด้วยการ ครอบข้อความด้วยป้าย (tag) แทนการกดปุ่ม browser อ่านป้ายแล้วแสดงผลตามนั้น

HTML ย่อมาจาก Hyper Text Mark-up Language เป็นโค้ดพื้นฐานที่อยู่เบื้องหลังหน้าเว็บ

HTML คืออะไร (สไลด์ HTML)

  • Hypertext Markup Language: ภาษาที่ กำหนดโครงสร้างของเนื้อหา บนหน้าเว็บ เกิดขึ้นราวปี 1989
  • หน้าที่หลักคือ ให้ความหมายกับข้อความที่ไม่มีโครงสร้าง: ข้อความชุดเดียวกัน ถ้าครอบชื่อเรื่องด้วย <h1> และเนื้อความด้วย <p> browser ก็รู้ว่าส่วนไหนคือหัวข้อ ส่วนไหนคือย่อหน้า
html
<h1>The FIFA World Cup 2026</h1>
<p>
  The 23rd edition of the tournament but the first to
  feature 48 teams and three host countries
</p>
  • ผู้ที่ได้ใช้ HTML ไม่ได้มีแค่ web developer และ software developer แต่รวมถึง marketing professional ด้วย เช่น การทำข้อความใน LINE และ Email

Tag

  • ไฟล์ HTML คือไฟล์ข้อความธรรมดาที่มีโค้ดอยู่ใน tag
  • tag เขียนใน วงเล็บมุม < และ >
  • tag บอก browser ว่าจะ แสดงเนื้อหาอย่างไร
  • tag ส่วนใหญ่มาเป็น คู่: tag เปิด และ tag ปิด (มี / นำหน้า)
Tag เปิดTag ปิด
<html></html>
<head></head>
<title></title>
<body></body>

tag ที่ ไม่ต้องมี tag ปิด เช่น <br> ซึ่งขึ้นบรรทัดใหม่ (เหมือนกด Enter)

หมายเหตุจากเอกสาร

เอกสารแบบฝึกหัดเขียน tag ด้วยตัวพิมพ์ใหญ่ (<HTML>, <BODY>) และใช้ Internet Explorer กับ Notepad++ HTML ไม่แยกตัวพิมพ์เล็กใหญ่ใน tag จึงใช้ได้ทั้งสองแบบ แต่ปัจจุบันนิยมตัวพิมพ์เล็ก บทเรียนนี้ใช้ตัวพิมพ์เล็ก

โครงสร้างของเอกสาร

html
<html>
  <head>
    <title>Basic</title>
  </head>
  <body>
    My name is xxx
  </body>
</html>
Tagหน้าที่
<html>tag แรกเสมอ บอก browser ว่าเนื้อหาที่ตามมาเป็น HTML
<head>ข้อมูลเกี่ยวกับหน้า (ไม่แสดงในเนื้อหา)
<title>ข้อความที่แสดงบน title bar / แท็บ ของ browser — เป็น element เดียวที่ต้องมีใน head
<body>เนื้อหาหลัก ที่ผู้ใช้มองเห็น

head กับ body (สไลด์ HTML)

html
<html>
  <head>
    <title>My Website</title>
    <meta name="description">     <!-- ไม่ต้องมี tag ปิด -->
  </head>
  <body>
    <h1>HTML is awesome!</h1>
    <p>Look, I build a website</p>
    <img src="greeting.png" />    <!-- self-closing tag -->
  </body>
</html>
ส่วนสไลด์ว่าอย่างไร
<head>เก็บสิ่งที่ ไม่ได้แสดงบนหน้าเว็บโดยตรง เช่น <title> และ <meta> (<meta> ไม่ต้องมี tag ปิด)
<body>เก็บ UI จริงที่ผู้ใช้มองเห็น
Self-closing tagtag ที่ไม่มีเนื้อหาข้างใน เขียนปิดในตัว เช่น <img src="…" />

DOM tree

browser อ่านไฟล์ index.html แล้วสร้างเป็น DOM (Document Object Model): ต้นไม้ของ object

text
Document
└── Root element: <html>
    ├── Element: <head>
    │   └── Element: <title>
    │       └── Text: "My title"
    └── Element: <body>
        ├── Element: <a>  ── Attribute: "href"
        │   └── Text: "My link"
        └── Element: <h1>
            └── Text: "My header"
  • บนสุดคือ Document ตามด้วย root element คือ <html>
  • element, attribute และ ข้อความ (text) ต่างก็เป็น node ในต้นไม้
  • JavaScript แก้หน้าเว็บโดยแก้ node ในต้นไม้นี้ (ดูบท DOM)

ลำดับการปิด: ปิด </body> ก่อน แล้วจึง </html> (tag ที่เปิดทีหลังต้องปิดก่อน) และควร ย่อหน้า (indent) เพื่อให้อ่านง่าย

เสริมโครงสร้างที่ใช้จริงในปัจจุบัน

เอกสาร HTML5 เริ่มด้วย <!DOCTYPE html> ใส่ภาษาใน <html lang="th"> และมี <meta charset="UTF-8"> ใน head เพื่อให้ภาษาไทยแสดงถูกต้อง (สไลด์ชุด HTML JavaScript มี <meta charset="UTF-8"> ในตัวอย่าง)

สีพื้นหลังและ style

attribute style ใส่ CSS ลงใน tag ได้โดยตรง:

สะกดแบบอเมริกัน: color (ไม่ใช่ colour) และ center (ไม่ใช่ centre)

Tagหน้าที่

<head>ข้อมูลของหน้า

แบ่งส่วนด้วย div

สไลด์ HTML: HTML มี structural tag ซึ่งมักใช้ จัดกลุ่ม element เข้าด้วยกัน เช่น <div> ที่ครอบโลโก้และ link ไว้ด้วยกัน

<div>…</div> แบ่งหน้าออกเป็นส่วน ๆ แล้วจัดวางด้วย CSS เช่น ให้ส่วนเมนู float ไปอยู่ด้านขวา:

html
<div style="float:right; width:200px;">เมนู</div>
<div>เนื้อหาหลัก</div>

ตัวอย่างไล่ทีละขั้น

โจทย์: หน้าเว็บนี้แสดงอะไรบ้าง และอะไรอยู่ที่ title bar

html
<html>
  <head>
    <title>Text sizes</title>
  </head>
  <body style="background-color:red;">
    <h1>Test heading 1</h1>
    <h3>Test heading 3</h3>
    <p>I am <b>amazing</b><br>and <u>impressed</u></p>
    <hr>
    <a href="http://www.bbc.co.uk/news">To the news!</a>
  </body>
</html>
  1. title bar / แท็บ: Text sizes (จาก <title> ซึ่งอยู่ใน <head> ไม่แสดงในเนื้อหา)
  2. พื้นหลังของหน้า: สีแดง (จาก style ของ <body>)
  3. หัวข้อใหญ่สุด "Test heading 1" ตามด้วยหัวข้อขนาดกลาง "Test heading 3"
  4. ย่อหน้า: "I am amazing" แล้วขึ้นบรรทัดใหม่ (<br>) "and impressed" (ขีดเส้นใต้)
  5. เส้นแนวนอน
  6. link "To the news!" คลิกแล้วไป http://www.bbc.co.uk/news

จุดที่มักพลาด

1. ลืม tag ปิด

tag ส่วนใหญ่ต้องปิด ยกเว้น tag อย่าง <br>, <hr>, <img>

2. ปิด tag ไขว้กัน

<b><u>ข้อความ</b></u> ผิด ต้องปิดตัวที่เปิดทีหลังก่อน: <b><u>ข้อความ</u></b>

3. ใส่เนื้อหาไว้ใน head

เนื้อหาที่ผู้ใช้เห็นอยู่ใน <body> ส่วน <title> อยู่ใน <head>

4. คิดว่า title คือหัวข้อบนหน้า

<title> แสดงที่ title bar หัวข้อบนหน้าใช้ <h1>

5. สลับ h1 กับ h6

<h1> ใหญ่สุด

6. สับสน element กับ tag

tag คือ <p> หรือ </p> ส่วน element คือทั้งก้อนรวมเนื้อหา

7. สลับ innerText กับ innerHTML

innerText ได้เฉพาะข้อความ innerHTML ได้ HTML ข้างในรวม tag ลูก

8. สะกด colour / centre

ใช้ color และ center

สรุปก่อนสอบ

  • HTML กำหนดโครงสร้างของเนื้อหา (ราวปี 1989) · HTML5 ปี 2008 · ปัจจุบันเป็น The Living Standard
  • Element = tag เปิด + เนื้อหา + tag ปิด · attribute เขียนใน tag เปิด เช่น class="css"
  • innerText = ข้อความข้างใน · innerHTML = HTML ข้างในรวม tag ลูก
  • <head> เก็บสิ่งที่ไม่แสดงโดยตรง (title, meta) · <body> คือ UI ที่ผู้ใช้เห็น · <img /> เป็น self-closing
  • DOM tree: Document → root <html> → head / body → element, attribute, text
  • HTML = Hyper Text Mark-up Language · tag อยู่ในวงเล็บมุม ส่วนใหญ่มาเป็นคู่เปิด–ปิด · <br> ไม่ต้องปิด
  • โครงสร้าง: <html> (tag แรกเสมอ) → <head> + <title> (แสดงที่ title bar) → <body> (เนื้อหาหลัก)
  • <p> ย่อหน้า · <h1>–<h6> หัวข้อ (h1 ใหญ่สุด) · <b> ตัวหนา · <u> ขีดเส้นใต้ · <br> ขึ้นบรรทัดใหม่ · <hr> เส้นแนวนอน
  • <img src="…" height="…" width="…"> · รูปถ่าย jpg, การ์ตูน gif/png
  • <a href="…">ข้อความ</a>: URL, mailto:, หรือชื่อไฟล์หน้าอื่น
  • style="background-color:yellow;" · <div> แบ่งส่วน (เช่น float ขวา)
