## Stack คืออะไร

stack เป็นโครงสร้างข้อมูลแบบ **LIFO** (Last In, First Out) — ข้อมูลที่ใส่เข้าไปทีหลังสุดจะถูกนำออกก่อน
เหมือนจานที่ซ้อนกัน หยิบได้เฉพาะใบบนสุด

- `push(x)` — วาง `x` ไว้บนสุด
- `pop()` — นำตัวบนสุดออกและคืนค่า
- `peek()` — ดูค่าบนสุดโดยไม่นำออก

## ข้อสังเกต

| สถานการณ์ | เกิดเมื่อ | ชื่อเรียก |
| --- | --- | --- |
| push ไม่ได้ | stack เต็ม | stack overflow |
| pop ไม่ได้ | stack ว่าง | stack underflow |

```ts
function push(x: number) {
  if (top === capacity - 1) throw new Error('stack overflow');
  items[++top] = x;
}
```
