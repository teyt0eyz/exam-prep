## นึกภาพก่อน

ตารางยอดขาย 1,000 แถว หัวหน้าถามสามคำถาม: รวมเท่าไร เฉพาะสาขากรุงเทพเท่าไร และสินค้ารหัส P007 ราคาเท่าไร
คำตอบคือสามสูตร: `SUM`, `SUMIF` และ `XLOOKUP` งานใน Excel ส่วนใหญ่ใช้สูตรวนอยู่ไม่ถึงยี่สิบตัว

## พื้นฐานของสูตร

- สูตรขึ้นต้นด้วย **`=`** เสมอ
- `A1:A10` คือ **ช่วง (range)** ตั้งแต่ A1 ถึง A10
- ข้อความในสูตรต้องอยู่ใน **เครื่องหมายคำพูด** เช่น `"กรุงเทพ"`

### การอ้างอิงเซลล์และเครื่องหมาย $

| แบบ | เขียน | เมื่อ copy สูตรไปเซลล์อื่น |
|---|---|---|
| **Relative** | `A1` | เลื่อนตามทั้งแถวและคอลัมน์ |
| **Absolute** | `$A$1` | **ล็อก** ทั้งแถวและคอลัมน์ |
| **Mixed** | `$A1` หรือ `A$1` | ล็อกเฉพาะคอลัมน์ หรือเฉพาะแถว |

กด **F4** ขณะแก้สูตรเพื่อสลับรูปแบบ ตัวอย่างที่ต้องใช้ `$`: คำนวณ VAT ทุกแถวโดยอ้างอัตราภาษีในเซลล์เดียว → `=B2*$F$1`

## ฟังก์ชันสรุปผล

| ฟังก์ชัน | ทำอะไร |
|---|---|
| `SUM(range)` | ผลรวม |
| `AVERAGE(range)` | ค่าเฉลี่ย |
| `MAX(range)` / `MIN(range)` | ค่าสูงสุด / ต่ำสุด |
| `COUNT(range)` | นับเซลล์ที่เป็น **ตัวเลข** |
| `COUNTA(range)` | นับเซลล์ที่ **ไม่ว่าง** (ทุกชนิด) |

## IF: ตัดสินใจ

```text
=IF(เงื่อนไข, ค่าเมื่อจริง, ค่าเมื่อเท็จ)
=IF(C2>=50, "ผ่าน", "ไม่ผ่าน")
```

ซ้อนกันหรือใช้ร่วมกับ `AND` / `OR` ได้ เช่น `=IF(AND(C2>=50, D2="ส่งงาน"), "ผ่าน", "ไม่ผ่าน")`

## สรุปแบบมีเงื่อนไข

| ฟังก์ชัน | รูปแบบ |
|---|---|
| `SUMIF` | `=SUMIF(ช่วงเงื่อนไข, เงื่อนไข, ช่วงที่จะรวม)` |
| `COUNTIF` | `=COUNTIF(ช่วง, เงื่อนไข)` |
| `AVERAGEIF` | `=AVERAGEIF(ช่วงเงื่อนไข, เงื่อนไข, ช่วงที่จะเฉลี่ย)` |
| `SUMIFS` / `COUNTIFS` | หลายเงื่อนไข — ใน `SUMIFS` **ช่วงที่จะรวมอยู่ตัวแรก** |

```text
=SUMIF(B2:B9, "กรุงเทพ", E2:E9)
=COUNTIF(D2:D9, "Cash")
=SUMIFS(E2:E9, B2:B9, "กรุงเทพ", C2:C9, "Member")
```

## ค้นหาข้อมูล

| | `VLOOKUP` | `XLOOKUP` |
|---|---|---|
| รูปแบบ | `=VLOOKUP(ค่าที่หา, ตาราง, ลำดับคอลัมน์, FALSE)` | `=XLOOKUP(ค่าที่หา, ช่วงที่หา, ช่วงที่คืนค่า, ค่าเมื่อไม่พบ)` |
| ทิศทาง | หาในคอลัมน์ **ซ้ายสุด** ของตาราง แล้วคืนค่าจากคอลัมน์ทางขวา | หาได้ทุกทิศ |
| ตรงทุกตัว | ต้องใส่ `FALSE` (หรือ 0) เอง | เป็นค่าเริ่มต้น |
| ไม่พบ | คืน `#N/A` | กำหนดข้อความได้ในตัว |
| รุ่นของ Excel | ทุกรุ่น | Excel 2021 และ Microsoft 365 |

```text
=VLOOKUP("P007", A2:C100, 3, FALSE)
=XLOOKUP("P007", A2:A100, C2:C100, "ไม่พบ")
```

## ฟังก์ชันข้อความและวันที่

| ฟังก์ชัน | ทำอะไร | ตัวอย่าง → ผล |
|---|---|---|
| `LEFT` / `RIGHT` / `MID` | ตัดข้อความ | `LEFT("INV-001", 3)` → INV |
| `LEN` | จำนวนตัวอักษร | `LEN("Excel")` → 5 |
| `TRIM` | ตัดช่องว่างเกิน | `TRIM("  A  B ")` → A B |
| `UPPER` / `LOWER` / `PROPER` | เปลี่ยนตัวพิมพ์ | `PROPER("john doe")` → John Doe |
| `&` หรือ `CONCAT` / `TEXTJOIN` | ต่อข้อความ | `A2 & " " & B2` |
| `TODAY()` | วันที่วันนี้ | |
| `TEXT` | จัดรูปแบบค่าเป็นข้อความ | `TEXT(1234.5, "#,##0.00")` → 1,234.50 |

## IFERROR: จัดการ error

```text
=IFERROR(สูตร, ค่าเมื่อเกิด error)
=IFERROR(VLOOKUP(A2, สินค้า!A:C, 3, FALSE), "ไม่พบรหัส")
```

| Error | สาเหตุที่พบบ่อย |
|---|---|
| `#N/A` | ค้นหาแล้วไม่พบ |
| `#DIV/0!` | หารด้วยศูนย์หรือเซลล์ว่าง |
| `#VALUE!` | ชนิดข้อมูลผิด เช่น บวกข้อความกับตัวเลข |
| `#REF!` | อ้างถึงเซลล์ที่ถูกลบ |
| `#NAME?` | พิมพ์ชื่อฟังก์ชันผิด |

| คีย์ลัด | ทำอะไร |
|---|---|
| Ctrl + C / V / X / Z | คัดลอก / วาง / ตัด / เลิกทำ |
| Ctrl + ลูกศร | กระโดดไปขอบของข้อมูล |
| Ctrl + Shift + ลูกศร | เลือกไปจนสุดขอบของข้อมูล |
| Ctrl + T | แปลงช่วงเป็น **Table** |
| Ctrl + Shift + L | เปิด / ปิด **Filter** |

| F4 | สลับ `$` ในสูตร หรือทำคำสั่งล่าสุดซ้ำ |
| Ctrl + E | **Flash Fill** (เติมตามรูปแบบที่ทำให้ดู) |

## ตัวอย่างไล่ทีละขั้น

ข้อมูล (แถว 2–5):

| แถว | B: Branch | C: Type | E: Total |
|---|---|---|---|
| 2 | กรุงเทพ | Member | 500 |
| 3 | เชียงใหม่ | Normal | 300 |
| 4 | กรุงเทพ | Normal | 200 |
| 5 | กรุงเทพ | Member | 400 |

| สูตร | คิดอย่างไร | ผล |
|---|---|---|
| `=SUM(E2:E5)` | 500 + 300 + 200 + 400 | **1400** |
| `=SUMIF(B2:B5, "กรุงเทพ", E2:E5)` | แถว 2, 4, 5 → 500 + 200 + 400 | **1100** |
| `=COUNTIF(C2:C5, "Member")` | แถว 2 และ 5 | **2** |
| `=SUMIFS(E2:E5, B2:B5, "กรุงเทพ", C2:C5, "Member")` | แถว 2 และ 5 → 500 + 400 | **900** |
| `=AVERAGE(E2:E5)` | 1400 ÷ 4 | **350** |
| `=IF(E3>=350, "สูง", "ต่ำ")` | E3 = 300 ไม่ถึง 350 | **ต่ำ** |

## จุดที่มักพลาด

- ลืม `$` เมื่อ copy สูตรที่อ้างเซลล์คงที่ — เซลล์อ้างอิงจะเลื่อนตาม
- ใช้ `COUNT` นับข้อความ — `COUNT` นับเฉพาะตัวเลข ต้องใช้ `COUNTA`
- ลืม `FALSE` ใน `VLOOKUP` — จะค้นแบบใกล้เคียงและอาจได้ค่าผิดโดยไม่มี error
- ให้ `VLOOKUP` หาค่าที่อยู่ทางซ้ายของคอลัมน์ค้นหา — ทำไม่ได้ ใช้ `XLOOKUP`
- สลับลำดับ argument ของ `SUMIF` กับ `SUMIFS` — `SUMIF` ช่วงที่รวมอยู่ **ท้าย** ส่วน `SUMIFS` อยู่ **หน้า**
- ตัวเลขถูกเก็บเป็นข้อความ (ชิดซ้าย) ทำให้ `SUM` ได้ 0
