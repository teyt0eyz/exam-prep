## นึกภาพก่อน

นักบัญชีบันทึกรายการลงสมุดรายวัน แล้วต้องคัดลอกตัวเลขเดิมไปลงบัญชีแยกประเภท รวมยอดทำงบทดลอง แล้วทำงบการเงิน ตัวเลขชุดเดียวถูกพิมพ์ซ้ำสามสี่รอบ ผิดรอบไหนก็ผิดทั้งงบ
คอร์สนี้ทำให้ **พิมพ์ครั้งเดียวที่สมุดรายวัน แล้วกดปุ่ม** ที่เหลือ Excel ทำเอง

## แนวคิดการพัฒนาโปรแกรม (Chapter 1)

| ขั้น | ในคอร์สนี้ |
|---|---|
| **Requirement** | โปรแกรมบัญชี โดย **บันทึกจากสมุดรายวัน** |
| **Design** | **ออกแบบขั้นตอนการทำงาน** |
| **Development** | **เลือกใช้เครื่องมือ** ในการพัฒนา |
| **Test** | ทดสอบ |

### ขั้นตอนการทำงานของระบบ

**บันทึกรายการสมุดรายวัน → สรุปจัดการบัญชีแยกประเภท → สรุปงบทดลอง → จัดทำงบการเงิน**

สิ่งที่ออกแบบไว้ (Design):

- มี **ปุ่มกดเพื่อบันทึก**
- มี **ปุ่มกดดูแยกประเภท**
- **สรุปข้อมูลจากสมุดรายวัน**

**ข้อมูล Master** (ข้อมูลหลักที่ทุกส่วนอ้างถึง):

- **ผังบัญชี**
- **รายการย่อในงบการเงิน**

### เครื่องมือที่เลือกใช้ (Development)

| ส่วนของระบบ | เครื่องมือ |
|---|---|
| บันทึกรายการสมุดรายวัน | **User interface** และ **VBA** |
| สรุปบัญชีแยกประเภท และงบทดลอง | **Pivot** |
| จัดทำงบการเงิน | **Pivot** |
| ข้อมูล Master | **Database** (ตารางใน Excel) |

## User Interface (Chapter 2)

1. **ออกแบบ Database**: ผังบัญชี และรายการย่อในงบการเงิน
2. **ออกแบบสมุดรายวัน**: หน้าที่ผู้ใช้กรอกรายการ
3. **ประยุกต์ใช้ Function**: **Data validation** และ **XLOOKUP**
4. **เพิ่มปุ่ม** เพื่อสั่งให้ VBA ทำงาน

### เปิดแท็บ Developer ก่อนเพิ่มปุ่ม

สไลด์แสดงหน้าต่าง **Excel Options → Customize Ribbon** โดยติ๊กถูกที่ **Developer** ในรายการ Main Tabs
แท็บ Developer ไม่แสดงโดยค่าเริ่มต้น ต้องเปิดก่อนจึงจะแทรกปุ่มและเขียน VBA ได้

<Extra title="เมนูในแท็บ Developer ที่ใช้กับงานนี้">

| เมนู | ใช้ทำอะไร |
|---|---|
| File → Options → **Customize Ribbon** → ติ๊ก **Developer** | แสดงแท็บ Developer |
| Developer → **Insert → Button (Form Control)** | วาดปุ่มบน sheet แล้วเลือก macro ที่จะผูก (Assign Macro) |
| Developer → **Visual Basic** (Alt + F11) | เปิดหน้าต่างเขียนโค้ด VBA |
| Developer → **Macros** (Alt + F8) | ดูรายการ macro และสั่งรัน |
| Data → **Data Validation** | กำหนดค่าที่อนุญาตให้กรอก เช่น List |
| บันทึกไฟล์เป็น **.xlsm** | ไฟล์ Excel ที่เก็บ macro ได้ (.xlsx เก็บไม่ได้) |

</Extra>

| Function | ใช้ทำอะไรในหน้าบันทึก |
|---|---|
| **Data validation** | จำกัดค่าที่กรอกได้ เช่น ทำ dropdown ให้เลือกรหัสบัญชี **จากผังบัญชีเท่านั้น** กันการพิมพ์ผิด |
| **XLOOKUP** | นำรหัสบัญชีที่เลือกไป **ค้นหาในผังบัญชี** แล้วดึงชื่อบัญชีมาแสดงอัตโนมัติ |

```text
=XLOOKUP(B5, ผังบัญชี[รหัส], ผังบัญชี[ชื่อบัญชี])
```

อ่านว่า: หาค่าใน B5 จากคอลัมน์รหัส แล้วคืนค่าจากคอลัมน์ชื่อบัญชีในแถวเดียวกัน

## VBA Programming (Chapter 3)

**VBA** (Visual Basic for Applications) คือภาษาโปรแกรมที่ฝังอยู่ใน Excel ใช้สั่งงานซ้ำ ๆ ให้ทำเองอัตโนมัติ

| หัวข้อในสไลด์ | ความหมาย | ตัวอย่าง |
|---|---|---|
| **Variable (Integer, Double)** | ตัวแปร: Integer เก็บ **จำนวนเต็ม**, Double เก็บ **ทศนิยม** | `Dim i As Integer` / `Dim total As Double` |
| **MsgBox** | แสดงกล่องข้อความ | `MsgBox "Hello World"` |
| **Range("A1").Value** | **อ่านหรือเขียนค่า** ในเซลล์ | `Range("A1").Value = 100` |
| **For loop** | **ทำซ้ำ** ตามจำนวนรอบ | `For i = 2 To 10 … Next i` |

<DocNote>

สไลด์เขียนคำสั่งแสดงข้อความว่า `msg("Hello World")` ซึ่งเป็นการเขียนย่อ ใน VBA จริงคำสั่งคือ **`MsgBox "Hello World"`**
จำนวนเงินควรเก็บในตัวแปรแบบ Double (หรือ Currency) เพราะ Integer เก็บทศนิยมไม่ได้

</DocNote>

### ปุ่ม Post

เมื่อ **คลิก Post** โค้ด VBA ทำสองขั้น:

1. **ตรวจสอบรายการ Dr Cr ต้องดุลกัน**
2. **สรุปรายการไปรายการแยกประเภทและงบทดลอง**

โค้ดด้านล่างเป็น **ตัวอย่างที่เขียนขึ้นตามสองขั้นของสไลด์** (สไลด์ไม่ได้แสดงโค้ดจริง):

```vb
Sub Post()
    Dim i As Integer
    Dim totalDr As Double, totalCr As Double

    For i = 2 To 10
        totalDr = totalDr + Range("C" & i).Value
        totalCr = totalCr + Range("D" & i).Value
    Next i

    If totalDr <> totalCr Then
        MsgBox "Dr และ Cr ไม่ดุลกัน"
        Exit Sub
    End If

    ' ดุลแล้ว: คัดลอกรายการไปเก็บในตารางข้อมูล แล้ว Refresh Pivot
End Sub
```

โค้ดนี้ใช้ครบทั้งสี่หัวข้อ: ตัวแปร Integer และ Double, For loop, `Range(...).Value` และ MsgBox

### ใช้ VBA สร้างรายงาน

- รายงาน **งบทดลอง**
- **แบบฟอร์มหัก ณ ที่จ่าย แบบ ภ.ง.ด.1ก**

ตัวอย่างรายงานบัญชีอื่นที่นำ VBA ไปใช้ได้:

- รายงาน **Cashflow forecast** (ประมาณการเงินรับ-จ่ายล่วงหน้า)
- รายงาน **งบประมาณ** รายปี / ไตรมาส
- **กระดาษทำการ** สำหรับผู้สอบบัญชี

## Pivot Tables และ Pivot Charts ในงานบัญชี (Chapter 4)

ตัวอย่าง Pivot Table ในสไลด์: **Category** อยู่ที่ Filters (เลือก All), **Country** อยู่ที่ Rows, **Product** อยู่ที่ Columns (Apple, Banana, Beans, Broccoli, Carrots, Mango, Orange) และ **Sum of Amount** อยู่ที่ Values มี Grand Total ทั้งแถวและคอลัมน์
จากนั้นทำ Pivot Chart แบบแท่ง แล้วใช้หน้าต่าง **Change Chart Type** เปลี่ยนเป็น **Pie** เพื่อดูสัดส่วนของสินค้า Beans แยกตามประเทศ (รายการชนิดกราฟในหน้าต่าง: Column, Line, Pie, Bar, Area, X Y (Scatter), Map, Stock, Surface, Radar, Treemap, Sunburst, Histogram, Box & Whisker, Waterfall, Funnel)

เมื่อรายการที่ Post แล้วถูกเก็บเป็นตารางแบบ Transaction การสรุปก็เป็นงานของ Pivot (ตารางด้านล่างเป็นการประยุกต์ที่เขียนขึ้นตามหัวข้อของสไลด์):

| รายงาน | Pivot Table |
|---|---|
| บัญชีแยกประเภท | Rows: บัญชี → วันที่ · Values: Sum of Dr, Sum of Cr |
| งบทดลอง | Rows: บัญชี · Values: Sum of Dr, Sum of Cr |
| งบการเงิน | Rows: รายการย่อในงบการเงิน (จาก Master) · Values: ยอดสุทธิ |

Pivot Chart ใช้แสดงภาพรวม เช่น ค่าใช้จ่ายแต่ละหมวด หรือรายได้รายเดือน

## ตัวอย่างไล่ทีละขั้น

บันทึก: ขายสินค้า 10,000 บาท รับเงินสด 3,000 ที่เหลือเป็นเงินเชื่อ

| บัญชี | Dr | Cr |
|---|---|---|
| เงินสด | 3,000 | |
| ลูกหนี้การค้า | 7,000 | |
| รายได้ขาย | | 10,000 |
| **รวม** | **10,000** | **10,000** |

1. ผู้ใช้เลือกรหัสบัญชีจาก dropdown (**Data validation**) ชื่อบัญชีขึ้นเอง (**XLOOKUP**)
2. กด **Post** → For loop รวม Dr = 10,000 และ Cr = 10,000 → **ดุล**
3. โค้ดนำสามบรรทัดไปลงบัญชีแยกประเภท
4. งบทดลอง: เงินสด Dr 3,000 · ลูกหนี้การค้า Dr 7,000 · รายได้ขาย Cr 10,000 → รวมสองฝั่งเท่ากัน

ถ้ากรอกรายได้ขายเป็น 9,000 → Dr 10,000 ≠ Cr 9,000 → MsgBox แจ้งเตือน และ **ไม่มีอะไรถูกบันทึก**

## จุดที่มักพลาด

- เรียงขั้นตอนผิด — สมุดรายวัน → แยกประเภท → งบทดลอง → งบการเงิน
- คิดว่าระบบตรวจ Dr/Cr หลังบันทึก — ตรวจ **ก่อน** แล้วจึงสรุปไปแยกประเภท
- สลับหน้าที่ของ Data validation กับ XLOOKUP — ตัวแรก **จำกัดค่าที่กรอก** ตัวหลัง **ค้นหาและดึงค่า**
- ใช้ Integer เก็บจำนวนเงินที่มีสตางค์ — Integer เก็บได้เฉพาะจำนวนเต็ม
- คิดว่าข้อมูล Master คือรายการที่บันทึกทุกวัน — Master คือ **ผังบัญชี** และ **รายการย่อในงบการเงิน** ซึ่งไม่ค่อยเปลี่ยน
